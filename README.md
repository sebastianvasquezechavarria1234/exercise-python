# Python Exercises Collection

A collection of introductory Python exercises refactored with professional best practices, including Object-Oriented Programming (OOP), data persistence, and type hinting.

## Project Structure

- `patient_registry.py`: A system for managing medical patient turns and service statistics.
- `order_system.py`: A simple point-of-sale system for managing orders and generating reports.
- `water_consumption.py`: A tool for tracking and analyzing daily water intake.

## Features

- **Object-Oriented Design**: Core logic encapsulated in classes for better maintainability.
- **Data Persistence**: Information is saved to JSON files, allowing data to persist between sessions.
- **Robust Validation**: Input handling to prevent crashes and ensure data integrity.
- **Type Hinting**: Improved code readability and developer experience.

## How to Run

Ensure you have Python 3.8+ installed. You can run any of the scripts directly:

```bash
python patient_registry.py
python order_system.py
python water_consumption.py
```

## Requirements

No external dependencies are required as the project uses only the Python Standard Library.
